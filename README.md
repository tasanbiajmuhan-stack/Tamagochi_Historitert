# STEPPE TAMAGOTCHI

Интерактивная браузерная игра в стиле древней консоли полководца и современного терминала разработчика.

## Запуск

1. Откройте файл `index.html` в любом современном браузере.
2. Либо запустите локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Игровой сценарий

Игрок управляет Александром Македонским в степях саков. Нужно следить за сытостью, настроением, энергией, воинским духом, терпением и амбициями. Нужно кормить, отдыхать, принимать решения, выполнять задания, помогать лагерю и избегать критических падений характеристик.

## Основные механики

- Периодические изменения характеристик каждые несколько секунд.
- Различные скорости игры: пауза, обычная, быстрая.
- Генерация случайных заданий с кнопками принятия и выполнения.
- Случайные события с выбором решений.
- Журнал царских свитков и консольный вывод.
- Сохранение в localStorage, загрузка и сброс прогресса.
- Несколько игровых концовок.
- Выбор персонажа: Александр Македонский или Диоген.
- Достижения, рекорды и пасхалки.

## Сохранение

Игра автоматически сохраняет состояние в `localStorage` через интерфейс кнопок «Сохранить игру» и «Загрузить игру». При сбросе прогресса появится подтверждение.

## Контроль качества

Игра написана без внешних библиотек и не требует отдельного сервера для базового запуска.
